# **App Name**: TubeStats

## Core Features:

- Link Input: Input field to paste YouTube video link.
- Fetch Stats: Fetch video statistics (likes, comments, views) from YouTube API based on the provided link.
- Display Stats: Display the fetched statistics in a clear and readable format.
- Responsive Design: Responsive layout to adapt to both PC and mobile screens.

## Style Guidelines:

- Primary color: White (#FFFFFF) for clean interface.
- Secondary color: Light gray (#F0F0F0) for backgrounds and dividers.
- Accent: Teal (#008080) for interactive elements and highlights.
- Use a grid-based layout for responsiveness.
- Clear and readable sans-serif font for all text elements.
- Use simple, consistent icons for visual representation of statistics.
